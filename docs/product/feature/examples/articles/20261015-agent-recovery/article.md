# Agent 工具调用的可恢复执行

来源：[虚拟原文](https://example.com/agent-recovery) · 作者：Example Author · 日期：2026-10-14

> 人工构造的阅读格式示例。以下导读是示范文字，未实际调用 AI。

## 导读

AI 调用工具后超时，操作可能已经完成。这篇说明如何保存进度、查询结果，帮助判断能否重试。标签：Agent、可靠性、任务状态。

## 整理原文（虚拟内容）

示例系统先为工具调用分配稳定任务标识，并保存输入与状态，再执行工具。成功后持久化结果，重启时先读取该记录。

![可恢复执行的三个步骤](assets/diagram-60396a85deb4.svg)

图：保存任务、执行工具、确认结果。配图已归档到本篇 assets。

如果外部写请求超时，系统先查询目标状态，再决定是否重试。请求没有返回成功，不足以证明外部操作没有发生。

## 阅读提示

这个虚拟原文没有真实性能实验，也没有证明所有外部系统都支持查询结果，或能识别重复请求、避免把同一操作做两遍（即“幂等”）。
