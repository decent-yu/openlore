# 如何同时保证 Agent 执行和结论可追溯

> 虚拟调研产物示例；research_id：r-001；mode：local；未执行真实模型或网络调研。

## 问题与结论

这两个示例分别讨论执行状态与证据状态。可以在任务记录中同时保留运行身份与材料版本，以便回查执行结果及结论依据。此处是对示例的设计推断，不是已验证方案。

## 原文事实

- S1 提出保存任务标识、输入和状态；超时先核实目标。[原文 S1](../../articles/a-001/source.md)
- S2 提出按片段保留来源编号并声明未读范围。[原文 S2](../../articles/a-002/source.md)

## 机制与取舍

执行记录回答“动作是否完成”，证据记录回答“结论基于什么”。二者可以通过同一运行关联，但不应把网络成功等同于推论正确。

## 适用条件与建议

建议在原型中为一次研究保存输入版本、运行状态和引用清单，再用中断恢复及引用校验样例验证。
