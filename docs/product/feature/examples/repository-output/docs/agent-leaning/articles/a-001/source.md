## 执行记录

示例系统为每次工具调用分配稳定任务标识，先保存输入与状态，再执行工具。工具成功后保存结果，进程重启时先读取状态。

## 重试边界

如果写请求超时，应先查询目标状态，再决定是否重试。仅靠“请求没有返回成功”不能确定操作没有发生。

## 示例限制

本样例没有真实性能测试，未证明任意第三方 API 都支持幂等。
