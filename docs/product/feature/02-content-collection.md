# 采集能力

通过统一接口调用不同采集能力，获取可追溯的内容。新增来源或替换底层工具时，后续内容处理保持统一。

## 职责与流程

读取[来源配置](01-source-configuration.md) → 选择采集能力 → 发现条目或读取正文 → 转换统一结果 → 保存内容与状态 → 交给[内容处理](03-content-processing.md)。

- 公共来源由管理员配置，采集组决定哪些来源需要运行。
- 相同来源、配置和凭据范围的采集结果可以共享；各组的关键词筛选在内容处理阶段执行。
- 订阅发现与正文补抓分开。Feed 已有可用正文则直接使用；只有摘要时安排独立补抓，保留来源关联。

## 统一输入与输出

| 输入 | 约定 |
| --- | --- |
| 来源与能力 | 来源标识、能力标识、采集操作：发现条目或读取正文 |
| 目标与范围 | Feed/文章 URL 或平台目标、时间范围、单批数量上限 |
| 运行条件 | 上次续采状态、凭据引用、能力专用参数、超时与请求预算 |

| 输出 | 约定 |
| --- | --- |
| 内容条目 | 稳定标识、来源、原文与最终 URL、标题、作者、时间、正文/摘要、附件 |
| 内容质量 | 正文完整度、实际获取方式、缺失内容与原始响应依据 |
| 批次状态 | 成功、部分成功、失败或未变化；返回数量、覆盖范围与是否需要继续读取 |
| 续采与错误 | 可保存的下一状态、结构化错误、是否可重试及建议等待时间 |

字段、状态语义和调用示例见[采集接入设计](../../design/collection-adapters.md)。所有适配器都遵循同一约定，不将第三方库的原始返回值直接交给业务层。

## 能力接入清单

| 独立能力 | 状态 | 复用方案 / 说明 |
| --- | --- | --- |
| Web RSS/Atom：`web_feed` | **本期接入** | 优先复用 feedparser，统一解析两种订阅格式，处理源内标识、日期、条件请求与解析异常 |
| Web 文章读取：`web_page` | **本期接入** | HTTP 获取 + Trafilatura 正文提取；支持单篇导入与 Feed 正文补抓 |
| GitHub 数据：`github_api` | 后续候选 | 官方 API/SDK，获取 Releases 等数据；不同于 04 的仓库文件同步 |
| 动态网页：`web_browser` | 后续候选 | Playwright 等浏览器能力；处理确实需要渲染、交互的页面 |
| 托管 Web 采集：`web_service` | 后续候选 | Firecrawl 等服务，独立封装认证、结果与任务状态 |
| X 平台：`x_platform` | 后续候选 | 平台 API/工具，选型与实际覆盖能力待验证 |
| 微信公众号：`wechat_platform` | 后续候选 | WeRSS 等服务；如果上游已经输出标准 Feed，可直接接 `web_feed` |

RSSHub 同样可作为 Feed 提供者接入，无需为每个网站复制适配器。上述后续能力不计入本期交付。

## 本期来源与开源复用

- Cloudflare Blog 与 Simon Willison 均配置为 `web_feed`，共用同一能力目录；不足的正文交给 `web_page`。
- [feedparser](https://feedparser.readthedocs.io/en/latest/) 已提供 RSS/Atom 解析、日期和常见字段处理；[条件请求文档](https://feedparser.readthedocs.io/en/latest/http-etag/) 明确 304 代表未变化。
- [Trafilatura](https://trafilatura.readthedocs.io/en/latest/) 提供正文、元信息与结构化输出。本期复用其提取能力，应用层仍要检查正文质量和来源身份。
- 我们实现薄适配层、统一协议、持久状态及失败恢复，不重复实现通用 XML 解析器或正文提取算法。实际依赖版本在编码验收时锁定。

## 扩展与验收

- 每项独立基建能力一个代码目录，封装第三方依赖与映射；通过注册表接入，业务流程不按网站名硬编码分支。
- 返回摘要、验证页、解析异常、超时和无更新时，状态应能明确区分；未知发布日期不伪造、不静默丢弃。
- 只有条目与必要的待重试信息可靠保存后，才推进续采状态；HTTP 未变化不取消尚未完成的正文补抓。
- 同批内容重跑不重复入库；单个来源或补抓失败不阻塞其他来源；替换适配器不改变下游字段。
- 以上为接入规范；本期需实际完成两个适配器及其契约验证，当前文档不表示实现已完成。
