# 源码依据与研报交付

以讲清项目用途、架构、真实调用链、实现机制和设计取舍为目标。重要结论尽量说明对应文件、函数或普通源码链接；行号和代码节选按阅读需要提供，不要求精确行号、逐字引用、引用数量或 Commit。

清楚区分直接读到的实现、设计文档的陈述、自拟例子、分析推断和未知内容。没有运行测试时不要声称验证通过，没有测量时不编造数字。源码不可读取时如实报告失败。

已有研报是后续研究上下文，包括已生成但未归档的内容。结合这些资料选择值得深入的问题，不重复生成首篇概述，也不把历史结论当成当前源码事实。

交付 output/research.md，首行为具体标题。必要配图保存到 output/assets/ 并使用相对路径引用。不需要 evidence.json、complete 标记或额外的证据数据文件。
