# 研究方法参考

以下来源用于比较和改写调查方法，不是执行时需要安装的依赖。

- [Microsoft wiki-researcher](https://github.com/microsoft/skills/blob/main/.github/plugins/deep-wiki/skills/wiki-researcher/SKILL.md)：参考它对实际调用路径、数据流和逐项证据的重视。OpenLore 按研究问题选择调查视角，不采用固定轮数、图数或必填表格。
- [Data-System-School investigate-codebase](https://github.com/Data-System-School/agent-skills/blob/main/investigate-codebase/SKILL.md)：参考可检验的系统模型、边界追踪和主动寻找反证的思路。首次研读仍按用户要求建立整体认识；后续自主缩小或扩展范围，不固定组件数与阅读文件数。
- [ByteDance deer-flow github-deep-research](https://github.com/bytedance/deer-flow/blob/main/skills/public/github-deep-research/SKILL.md)：参考从整体认识逐步深化、对照资料并标注不确定性的思路。OpenLore 的源码来自本地快照，不采用它的 REST 源码采样、固定搜索次数、活跃度分析或 Mermaid 交付模板。
