# 汇报简报

读取 `input/article.md` 中已完成归档的任务结果。材料可能包含多个任务，系统已执行选文和去重。本步骤只生成汇报，不重新审核、调研、采集或发送消息。

输出内容：

1. **批次全局综述**：一小段说明本次汇报覆盖的主题和主要收获，不能把几篇文章推断为整个行业趋势。
2. 按任务或紧密相关的主题组织，每篇文章用一两句话说明价值，保留提供的绝对 GitHub/原文链接及调研标识。
3. 有材料支持时总结可采取的工程建议；跨任务观点不一致时如实保留差异。

只使用输入提供的事实、数字和链接。不编造新文章或引用，不把 `01-slug/article.md` 等相对路径当成群内可访问的链接。

最终回复为可直接发送的中文 Markdown 简报，无 JSON 外壳、无整篇代码围栏。篇幅适合群内快速阅读，优先信息密度。不要主动调用群通知工具。
